    About
    Blackout Coder
    
        
    Coding lessons grounded in plant work: PLC and HMI, SQL pulls, OEE loss reports, shift handoffs, Power BI, maintenance, inventory, lean.
    
      
    
    
    
    
      
    The sample plant
    
      
    Every lane and project uses the same plant: three machines (Conveyor 3, Hoop Driver 1 and Char Station 2), one week of faults and barrel counts, and the tables built from them. Rates, margins, suppliers, prices and every other figure are illustrative, not real plant data. Where a lesson invents a number to make a point, it says so.
    
      
    Where the outputs come from
    
      
    Every output shown was produced by running the code, never typed by hand. SQL runs on SQL Server 2022; Python, C#, C++, Java and JavaScript run for real. DAX, Power Query M, PLC ladder, Structured Text and Ignition run in teaching models built for this site; DAX and M are checked against the same question asked of SQL Server, and Ignition scripts run in real Jython 2.7.
    
      
    Your progress
    
      
    Progress is kept in this browser only. Nothing is sent anywhere. Use Save progress to move it to another device, and Load progress there.
    
      
    Something wrong?
    
      
    Report a problem opens a new issue on GitHub with the lesson filled in. It needs a free GitHub account. Typos, code that would not work on a real line, and confusing explanations are all worth reporting.
